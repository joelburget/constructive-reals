Constructive Reals

A calculator that never rounds. Every digit it prints is correct — ask for more and it computes them. Compare it against what ordinary 64-bit floating point (the numbers JavaScript uses) produces.

An OCaml implementation of Hans-J. Boehm's Towards an API for the Real Numbers, running in your browser via js_of_ocaml.
